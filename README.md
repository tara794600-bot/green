# 법무법인 나란

SVG 디자인을 바탕으로 구현한 반응형 홈페이지, 상세페이지, 비밀번호 기반 관리자 시스템입니다

```powershell
npm install
npm run dev
```

홈페이지: http://127.0.0.1:5173/  
관리자: http://127.0.0.1:5173/admin

참고 사이트의 홈 롤링 사례, 사기업체 등록·수정·노출 설정, 파워링크 URL 생성 기능을 포함합니다. [관리자 기능 대조표](./ADMIN_FEATURE_PARITY.md)에서 반영 항목을 확인할 수 있습니다.

관리자는 첫 접속에서 비밀번호를 정한 후 **비밀번호만 입력해 로그인**합니다.

사기업체 추가·수정 화면의 **상세 본문**에서 노션 방식의 블록 편집기를 사용할 수 있습니다. `블록 추가` 또는 빈 텍스트 블록의 `/`로 마크다운, 강조 박스, 숫자 카드, Mermaid 다이어그램, HTML, 이미지, 구분선을 추가합니다. 블록별 색상·배경·테두리·그림자·여백·정렬·애니메이션을 설정하고 드래그 또는 화살표로 순서를 바꿀 수 있습니다. `나란히 보기`에서 결과를 확인한 뒤 **저장하기**를 누르면 상세페이지에 반영됩니다.

목록용 요약과 대표 이미지는 기존 방식으로 유지됩니다. 본문은 최대 80개 블록·100,000자(블록당 20,000자)까지 저장하며 본문 이미지도 업로드할 수 있습니다. HTML은 안전한 태그와 표시용 인라인 스타일만 허용합니다. 스크립트, iframe, 이벤트 핸들러는 제외됩니다. 기존 업체 정보는 별도 변환 없이 그대로 표시됩니다.

Firebase·Telegram·Google Sheets 연동 코드를 포함합니다. 현재 키가 없어 개발용 로컬 저장을 사용합니다. 실제 연결과 배포 방법은 [운영 안내](./OPERATIONS.md)를 참고하세요.

```powershell
npm run lint
npm test
npm run test:e2e
npm run build
```

`npm run build`는 프런트엔드와 서버 렌더링 번들을 생성한 뒤, CommonJS의 ESM 직접 로딩이 제한된 환경에서 API·SSR 진입점을 검사합니다. Vercel 서버 함수에서 HTML 처리 라이브러리의 모듈 호환성 오류가 재발하지 않도록 이 검사를 배포 빌드에 포함합니다.
